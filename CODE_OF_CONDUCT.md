# Code of conduct

Dabir is a small project run by working researchers and engineers. Two rules cover it.

1. **Be direct about the work, decent to the person.** Disagree with a change in terms of the change: what it does, what it breaks, what the evidence is. Do not speculate about the person who made it. Reviews say what is wrong and what would be right.
2. **Nobody is here to be worn down.** Harassment, discrimination, threats, sustained hostility or publishing someone's private information end participation. Report it to the maintainer at the address in the repository profile, or through GitHub's report tools; reports are acted on within a week and kept private.

This applies in issues, pull requests, discussions, live sessions run for the project, and anywhere else the project is represented. The maintainer decides; a decision can be appealed once, in writing.
