Write the paper where the code is

Dabir is a desktop editor for scientific papers. Your LaTeX, the scripts behind the figures, the Git history, your coauthors and an AI agent share one window on your own machine. Nothing is uploaded. It is free and open source.

Download for macOS Windows Linux

Apple Silicon and Intel Macs, Windows 10 and later, Linux AppImage and deb. Or build it yourself: git clone https://github.com/surenalab/dabir

The agent is a coauthor you review, not a chatbot you paste from

Ask for a change in plain words: rerun the sweep with a finer grid, add the new baseline to Table 2, fix the compile error on line 1090. The agent works on a Git worktree of its own, with the compile log and your scripts, using whichever subscription you already have. Nothing touches your checkout until you have read the diff, hunk by hunk.

One buffer, three views

Visual reads like the compiled paper: equations, figures, tables and citations render in place, and whatever sits under your cursor shows its source. Source is the LaTeX with completion, spelling, grammar on demand, and predictive text learned from the paper itself. Split puts the source beside the PDF, which follows your cursor; double-click the PDF to land on the line.

Compile with the bundled engine, no TeX installation required. Errors and warnings become a list that jumps to the line, and each one can be handed to the agent with the instruction to fix the cause, not silence the message.

Coauthors without a server

Start a live session and a coauthor receives a mirror of the whole paper, figures and bibliography included, then edits with you in real time with their cursor in their colour. Machines connect directly, or through a small relay Dabir runs on yours; there is no service of ours in the middle and nothing to pay for. Comments anchor to the text, carry replies, and show as pins on the PDF. When the session ends, it becomes a commit.

Already on Overleaf? Import the zip, or pull and push through Overleaf's Git bridge and keep both.

Memory that lives in the repository

A .dabir folder next to the paper holds a brief of what the paper is, one-fact notes the agents leave for each other, the skills they follow, and a provenance graph from script to figure to table. It is committed with the paper, so every coauthor's agent, whichever vendor, starts from the same knowledge, and a stale figure is flagged before a reviewer sees it.

Plain facts

  • LicenceMIT. The source, the plan and the design notes are public.
  • PrivacyLocal first. Your paper stays on disk. Grammar checking is off until you name a server, because text would leave the machine.
  • PlatformsmacOS, Windows and Linux, one codebase, native menus on each.
  • CostFree. The agents run on the subscriptions you already have.
  • NameDabir, دبیر, is Persian for scribe. The mark is its first letter, written with a reed, and the calligrapher's dot.
