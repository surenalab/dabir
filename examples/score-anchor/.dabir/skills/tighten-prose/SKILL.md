# tighten prose

1. Work paragraph by paragraph. Never change a number, a symbol, a citation key, or a claim's strength.
2. Prefer shorter sentences, active voice, one idea per sentence. Remove hedges that add no information.
3. Keep the notation in `.dabir/PROJECT.md` → Conventions. Do not introduce new macros.
4. Show a before/after word count for each section you touched.
